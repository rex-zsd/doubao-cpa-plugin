## 连接器的跨目录阻塞

原来 acquire 在池级 mutex 内执行可用性检查、注册与等待启用，reap/retire 也在同一把锁内执行列表、断开及回读。一个目录的慢网络操作会拖住其他已经缓存的目录。

现在全局锁只保护内存状态和持久化检查点，网络请求均在锁外进行。同目录操作按 catalog key 协调，等待可响应 context 取消；不同目录可以独立前进。回收重新核对持有者并跳过正在检查或创建的目录。创建和断开仍先持久化意图，未知结果不重发同一次 POST；同目录创建未确认时，等待方也不会另建一份。容量、TTL、任务租约、账号/设备隔离及恢复格式保持不变。

race 回归分别无限暂停注册、可用性列表和断开请求，确认另一个热目录能在暂停解除前完成获取。同时覆盖同目录只创建一次、等待取消、回收与获取竞争、未确认创建、活跃租约、容量及重启/关闭。它证明消除跨目录的网络阻塞，不代表所有正常请求固定减少几秒。

## 原生覆盖和客户端语义

- Read：绝对路径的已知文本/代码扩展名，包括 `.txt/.go/.py/.js/.ts/.md/.json/.yaml/.sh` 等，以及 Dockerfile、Makefile、.gitignore 等文本文件名。保留可选 offset/limit，offset 从 1 开始。未知格式、PDF、媒体和 notebook 继续使用 MCP。
- Write：客户端明确声明的同名工具，绝对 file_path 和字符串 content，允许空内容。
- Edit：客户端明确声明的同名工具，绝对 file_path、非空 old_string、字符串 new_string、可选 replace_all。删除文本可使用空 new_string；不改写路径或内容。
- 前台 Bash 保持原行为；独立调用仍优先已有 MCP 批入口。

每项参数仍通过调用方原始 JSON Schema 校验。完整说明、schema、目录和历史保留；执行、审批及实际文件修改属于 HTTP 客户端。仅移除已验证的 Read 显示默认值和 Bash 默认沙箱选择。不兼容参数继续走 MCP。Write/Edit 与 Read/Bash 一样，使用原生 content/isError 格式回传，而非 MCP 的 raw_result；原始 native ID/input 保留。

`go test -race ./...` 全部通过。新增/扩展回归涵盖 Unicode、换行、空内容和删除文本的参数保真，HTTP 重放，真实结果/错误标志，以及全局开关关闭后恢复等待中的 Read/Write/Edit：恢复上传一次，不另发生成。

隔离实例使用独立设备标识，真实执行了六种扩展名（go、py、js、ts、md、json）的工具调用。读写依赖链逐字核对最终文件；替换不唯一、未命中文本、replace_all、客户端拒绝、空文件、长行 Unicode、缺失文件及空内容写入均通过。每个工具回合验证相同 HTTP 请求重放不会重复执行，最终上游回传内容和错误标志与实际客户端结果逐字一致；完整 32 工具目录及 effort 7 保留。

## 小样本性能对照

两版均使用 Orange 5.5、effort 7、完整 32 工具及相同客户端逻辑。隔离 helper 不启用连接器缓存，因此下表只对照工具路由，不能计作去锁收益。每条路径 3 次；没有删除较慢的已完成样本，也未做随机交错和大样本统计。

| 场景 | 0.3.19 整轮中位数 | 0.3.20 整轮中位数 | 本批结果 |
|---|---:|---:|---|
| `.go` 指定行 Read | 22.397 秒 | 23.482 秒 | 慢约 4.8%，未证明整轮收益 |
| 直接 Write 代码文件 | 24.603 秒 | 19.347 秒 | 快约 21.4% |

全部整轮样本（秒）：

- Read 旧版：20.185 / 22.397 / 27.409；新版：17.586 / 52.553 / 23.482。
- Write 旧版：24.693 / 24.603 / 22.662；新版：19.347 / 15.945 / 22.683。

首工具中位数分别为 Read 16.199 → 12.831 秒、Write 17.009 → 9.917 秒。路由减少了工具交出前的等待，但后续上游处理和长尾仍可抵消它；不能宣称所有编码任务都更快。

另一次旧版 Read → Write → Edit → Read 对照，在 Write 参数中丢了文件末尾换行，被客户端逐字检查拦住，没有执行写入。该未完成任务没有计入上表，也没有用它计算依赖链加速。新版对应链已完成逐字验收，37.934 秒只是一个样本，不能替代配对性能结论。这些检查覆盖所列语义，不是通用模型质量评测。
