后续 0.3.20 扩展代码文件 Read、Edit/Write 并解除连接器跨目录阻塞，见[连接器隔离与原生编辑验收](NATIVE_EXPANSION_CN.md)。本页保留 0.3.19 当时的范围和测量。

2026-10-18 已在线上官方 CPA v8.0.13 热加载 0.3.19，并启用 `plugins.configs.doubao-work.native_tools: true`。容器未重启；原有连接器缓存及其余配置均保留。配置的唯一语义变化是这个开关。

## 已接入的范围

兼容的单次调用和依赖链使用 Work 的结构化原生工具通道，省掉 MCP 工具发现步骤。HTTP 客户端仍在自己的环境执行工具，并回传真实结果。

- `Read`：客户端明确声明的同名工具；绝对路径 `.txt` 文本，可选 offset/limit，offset 从 1 开始。
- `Bash`：客户端明确声明的同名前台工具；命令、说明、毫秒 timeout 保留，不转换后台和提权请求。
- 参数通过客户端原始 JSON Schema 校验。只移除已验证的 Work 默认显示字段 `thumbnail_size=full` 和默认沙箱选择 `sandbox_permissions=use_default`；原始 native ID/name/input 保留用于回复关联。
- PDF、媒体、其他文件类型、其他工具、后台及提权仍走 MCP。允许并行时，多个独立调用优先使用原有 MCP 批入口。

模型、effort、完整工具目录、工具说明、schema 和历史没有降低或删减。新增原生说明导致提示词超限而完整 MCP 提示词仍可用时，整项任务退回 MCP，不截断上下文。路由策略保存在每项任务中；配置变化或恢复不会改变已交出的调用协议。此功能默认关闭，线上已显式开启。

底层仍然是 Work Agent；这次接入没有获得可绕过 Agent 的纯模型工具 API。

## 线上对照耗时

对照和新版均使用同一线上环境、Orange 5.5、effort 7、全部 32 个原始工具，保留原有连接器缓存。Read 读取真实文件的指定行；Bash 执行固定白名单 Python 命令，随机结果仅在实际执行后生成。每个工具阶段都做相同的 HTTP 幂等重放检查，最终回答逐字核对实际结果。

| 场景 | 旧版 / 新版次数 | 0.3.18 总耗时中位数 | 0.3.19 总耗时中位数 | 减少 |
|---|---:|---:|---:|---:|
| 文本 Read | 2 / 2 | 29.161 秒 | 24.208 秒 | 17.0% |
| 前台 Bash | 2 / 2 | 26.709 秒 | 23.369 秒 | 12.5% |

每条路径只有 2 次，顺序是旧版对照后新版，未做交错随机化；结果包含上游波动，不能作为长期加速保证或所有编码任务的质量评测。单次 Read 样本为旧版 30.243/28.080 秒，新版 29.983/18.433 秒；Bash 为旧版 22.152/31.266 秒，新版 23.683/23.055 秒。没有筛掉较慢的已完成样本。

| 检查 | 结果 |
|---|---|
| 原生 Read 指定行、前台 Bash 真实输出 | 通过；全部原始 32 工具定义及 effort 7 保留 |

| Bash 真正退出 7 | 通过；stderr、错误标志和最终失败结果保留 |
| HTTP 重放、调用 ID 与原始 input | 通过；每项任务只提交一次生成，客户端执行无重复 |
| 默认允许并行的单次 Read | 通过；仍走原生通道 |
| 两次独立 Read | 隔离和线上均通过；一个 MCP 批次，倒序提交结果仍正确 |

| Responses `/v1/responses` | 原生 Read 的真实文件结果和完整工具目录通过 |
